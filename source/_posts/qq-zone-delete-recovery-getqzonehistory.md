以前在 QQ 空间发布的说说，如果后来误删了，可以尝试使用开源项目 **GetQzonehistory** 找回部分历史内容。

需要先说明：这个工具不是传统意义上的“回收站恢复”，而是读取 QQ 空间仍然保留的历史互动记录。因此，曾经被点赞、评论或转发过的内容，恢复希望相对更大；完全没有互动的内容不一定能够找回。

## 一、项目地址

项目主页：<https://github.com/ll0v0ll/GetQzonehistory>

Windows 用户可以直接前往 [Releases 发布页](https://github.com/ll0v0ll/GetQzonehistory/releases) 下载预编译程序，不需要安装 Python 环境。

## 二、恢复原理

GetQzonehistory 主要通过两种方式获取数据：

1. 读取 QQ 空间历史消息列表中的点赞、评论、转发和留言记录；
2. 读取当前账号仍然存在的未删除说说。

程序会将两部分数据合并、去重，并导出到本地文件。已经删除的说说，只有在历史消息列表中仍然存在时才有机会被重建。

## 三、Windows 下载与运行

### 1. 下载程序

打开 [GetQzonehistory Releases](https://github.com/ll0v0ll/GetQzonehistory/releases)，下载最新版：

```text
GetQzonehistory_win.exe
```

建议新建一个单独文件夹保存程序，例如：

```text
D:\QQ空间恢复
```

不要从不明网站下载所谓的“破解版”或“增强版”。

### 2. 运行程序

双击 `GetQzonehistory_win.exe`。如果 Windows 弹出安全提示，先确认文件来自项目官方 GitHub Releases 页面。

### 3. 扫码登录 QQ

按照程序提示，用手机 QQ 扫码登录自己的账号。

登录时请注意：

- 只登录自己的 QQ 账号；
- 不要把二维码截图发给别人；
- 不要向任何人提供 QQ 密码或 Cookie；
- 二维码失效时，重新运行程序或刷新二维码即可。

### 4. 等待抓取完成

登录成功后，程序会自动获取历史消息并进行分析。数据量较多时，处理可能需要一段时间，期间尽量不要频繁关闭程序或重复扫码。

## 四、查看恢复结果

处理完成后，在程序所在目录中查找：

```text
resource/result
```

恢复结果通常会以 Excel、HTML 或其他导出文件保存：

- Excel 文件适合搜索和整理；
- HTML 文件可以直接用浏览器打开；
- 图片和其他媒体可能保存在结果目录的子文件夹中。

## 五、哪些内容可能无法恢复？

以下内容不一定能够找回：

- 从未被点赞、评论或转发过的说说；
- 仅自己可见且没有互动记录的说说；
- 删除时间非常久远的内容；
- QQ 空间接口已经不再返回的历史数据；
- 原始图片或视频链接已经失效的媒体。

因此，工具能做的是“从残留历史记录中尽可能重建”，并不能保证恢复全部删除内容。

## 六、常见问题

### 扫码后没有数据怎么办？

可以依次尝试：

1. 确认登录的是正确 QQ 账号；
2. 重新运行程序；
3. 等待更长时间；
4. 检查程序目录下是否生成了结果文件；
5. 查看项目 GitHub 的 Issues 页面是否有类似问题。

### 程序运行很慢怎么办？

历史数据越多，处理时间越长。建议保持程序运行，避免反复关闭和重新启动。

### 能不能恢复所有删除说说？

不能保证。项目依赖 QQ 空间接口中仍然存在的历史互动数据，如果内容已经被彻底清除，或者从未产生过互动，通常无法恢复。

## 七、安全注意事项

使用前请牢记：

- 只从官方 GitHub 仓库或 Releases 页面下载；
- 只操作自己拥有权限的 QQ 空间；
- 不要使用来历不明的修改版程序；
- 不要泄露密码、Cookie 和登录二维码；
- 恢复完成后，可以删除程序目录中的登录缓存；
- 不要把导出的个人数据上传到陌生网站。

## 总结

GetQzonehistory 适合用来尝试恢复 QQ 空间中曾经有过点赞、评论或转发记录的历史说说。使用流程很简单：下载 Windows 程序、扫码登录、等待抓取，再到 `resource/result` 目录查看导出结果。

不过，它并不是底层数据恢复工具，最终能找回多少内容取决于 QQ 空间仍然保留了多少历史记录。
