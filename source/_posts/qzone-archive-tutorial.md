QQ 空间保存了很多个人回忆，包括说说、相册、视频、留言和评论。为了避免账号异常、误删或平台接口变化导致内容丢失，可以使用开源项目 **QzoneArchive** 将有权限访问的 QQ 空间数据归档到本地。

本文以 Windows 为例，介绍如何使用 `Gaoshu705/QzoneArchive`。

> 注意：QzoneArchive 的定位是“归档和备份”，不是从腾讯服务器底层恢复已经彻底删除的数据。没有点赞或评论的动态，可能无法从互动记录中恢复。

## 一、项目地址

项目主页：<https://github.com/Gaoshu705/QzoneArchive>

项目 Releases：<https://github.com/Gaoshu705/QzoneArchive/releases>

QzoneArchive 支持 Windows、macOS、Linux 桌面端以及 Android，采用本地 SQLite 保存归档数据，并支持导出 HTML 离线查看。

## 二、主要功能

QzoneArchive 可以归档：

- QQ 空间动态和说说；
- 图片、相册和视频；
- 评论、回复和点赞记录；
- 留言板内容；
- 好友动态和互动记录。

项目还支持断点续传、任务记录、媒体时间轴和 HTML 导出，适合对数据量较大的 QQ 空间进行长期备份。

## 三、下载与安装

### 1. 下载项目

打开项目主页，进入 Releases 页面，下载适合自己系统的版本。

Windows 用户优先选择 `.exe` 或 Windows 安装包；如果发布页提供压缩包，下载后解压到一个单独文件夹，例如：

```text
D:\QQ空间归档
```

只建议从项目 GitHub 页面或项目作者提供的官方发布渠道下载，不要使用来历不明的修改版程序。

### 2. 直接从源码运行

如果没有适合自己系统的预编译程序，也可以按照项目说明从源码构建。项目开发环境主要需要：

- Rust 1.77 或更高版本；
- Node.js 20 或更高版本；
- Windows 用户需要 WebView2；
- Android 构建还需要 Android Studio、Android SDK 和 NDK。

源码构建命令如下：

```bash
npm install
npm run tauri dev
```

Windows 安装包构建命令：

```bash
npm run tauri:build:windows
```

普通用户更适合直接使用 Releases 中的预编译版本。

## 四、开始归档 QQ 空间

### 1. 启动程序

安装或解压完成后，启动 QzoneArchive。

首次使用时，程序会在本地创建数据目录，用于保存任务记录和归档数据库。

### 2. 扫码登录

在登录界面选择 QQ 扫码登录，然后使用手机 QQ 扫码并确认登录。

项目说明显示，二维码登录流程不会要求用户直接输入 QQ 密码；登录凭证只在程序后端内存中使用。

请注意：

- 只登录自己的 QQ 账号；
- 不要把二维码截图发给别人；
- 不要向任何人提供密码、Cookie 或登录凭证；
- 不要在公共电脑上长时间保留登录状态。

### 3. 选择归档内容

登录成功后，在归档任务中选择需要保存的内容，例如：

- 本人动态；
- 相册和照片；
- 视频；
- 留言板；
- 评论、点赞和回复；
- 好友动态。

第一次使用建议先选择少量内容进行测试，确认输出正常后再执行完整归档。

### 4. 开始任务

确认选项后开始归档。程序支持断点续传，网络中断或暂时停止后，可以继续之前的任务。

如果遇到访问频率限制，建议暂停任务，等待一段时间后再继续，不要短时间内反复启动大量请求。

## 五、查看归档结果

任务完成后，可以在程序提供的任务记录或数据目录中查看归档结果。

项目支持将数据导出为独立 HTML 文件，使用浏览器打开 HTML 文件即可离线浏览，不需要再次登录 QQ 空间。

归档数据默认保存在本地，建议将重要的归档目录复制到移动硬盘或其他可靠位置进行二次备份。

## 六、删除内容能否恢复？

QzoneArchive 的核心数据来源是 QQ 空间的移动端互动列表接口。该接口主要返回点赞、评论、回复、留言等互动通知。

因此：

- 曾经被点赞或评论过的内容，可能仍能从互动记录中归档；
- 完全没有互动记录的动态，可能无法恢复；
- 已被服务器彻底清除的数据无法通过此工具找回；
- 图片和视频是否能够下载，还取决于原始链接是否有效。

它更适合“尽早把现有 QQ 空间数据保存下来”，而不是保证恢复所有已经删除的内容。

## 七、常见问题

### 归档过程中需要一直打开 QQ 空间网页吗？

不一定。项目本身通过 QQ 登录流程和空间接口获取数据，具体以当前版本界面提示为准。

### 归档数据会上传到其他服务器吗？

项目 README 声明数据默认保存在本地，不上传到第三方服务器。不过，使用前仍应检查下载版本和项目代码来源。

### 为什么有些说说没有被归档？

可能是内容没有点赞或评论，也可能是接口限制、时间范围限制或原始媒体链接失效。

### 归档任务很慢怎么办？

QQ 空间数据量越大，任务耗时越长。建议开启断点续传，降低请求频率，并分批完成归档。

## 八、安全建议

- 只从 [QzoneArchive 官方 GitHub 仓库](https://github.com/Gaoshu705/QzoneArchive) 下载；
- 只归档自己拥有权限的账号和空间；
- 不要使用陌生人提供的打包程序；
- 不要泄露 QQ 密码、Cookie 和二维码；
- 归档完成后妥善保管本地数据库和媒体文件；
- 不要把包含个人信息的归档文件上传到陌生网站。

## 总结

QzoneArchive 适合用来将 QQ 空间的说说、相册、视频、留言和互动记录保存到本地。基本流程是：

```text
下载官方版本
    ↓
启动 QzoneArchive
    ↓
QQ 扫码登录
    ↓
选择归档模块
    ↓
开始任务并等待完成
    ↓
打开 HTML 或本地归档数据查看
```

如果你的目标是防止 QQ 空间内容以后丢失，建议尽早进行一次完整归档，并定期把归档目录复制到其他存储设备中。
