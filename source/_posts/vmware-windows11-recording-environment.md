录制软件下载、安装和注册教程时，经常会遇到一个问题：软件已经装在自己的电脑上了，没法从零开始演示。

我的解决办法是准备一台独立的 Windows 11 虚拟机。需要录制教程时，在虚拟机里重新操作；录制完成后，恢复备份或重新整理环境，不会影响主机系统。

## 1. 为什么选择虚拟机录教程

虚拟机相当于在现有电脑里开了一台“隔离的小电脑”：

- 主机里的软件和文件不会被教程操作打乱
- 可以专门安装录屏、截图和演示需要的软件
- 出现问题时，可以删除或恢复虚拟机文件
- 录制注册、安装和设置流程时，更容易从干净环境开始

需要注意的是，虚拟机不是无限性能的电脑。它和主机会共享内存、处理器、磁盘和网络，所以配置不能一味拉满。

## 2. 我的虚拟机配置

本文使用 VMware Workstation 17 Player，虚拟机文件放在 D 盘：

```text
位置：D:\VMware\Windows-教程录制
系统：Windows 11 x64
内存：4096 MB
处理器：2 个 CPU 内核
硬盘：100 GB
网络：NAT
```

如果主机只有 16 GB 内存，4 GB 给虚拟机是比较稳妥的起点。录制时还要给 OBS、浏览器和主机系统留出空间。只有当主机空闲内存仍然充足时，才考虑把虚拟机提高到 6 GB 或 8 GB。

## 3. 创建虚拟机时怎么选

### 安装来源

准备好微软官方 Windows 11 ISO 后，在 VMware 新建虚拟机，选择“安装程序光盘映像文件（ISO）”，然后选择 ISO 文件。

如果安装程序识别到 Windows 11，可以直接继续。新虚拟机里的磁盘是空的，安装时选择删除磁盘内容不会影响主机文件，但一定要确认当前操作对象是虚拟机磁盘。

### Windows 版本

家庭版和专业版都可以完成普通教程录制。专业版不会因为选择它就自动收费，但如果账号只有家庭版数字许可证，专业版通常不会自动激活，可能会出现激活提示和部分个性化限制。

如果只是录教程，家庭版已经够用；如果已经安装了专业版，也可以先继续使用，不需要为了版本重新安装一次。

### 磁盘空间

建议给虚拟硬盘 80～100 GB。这个数字是虚拟机能使用的上限，实际占用取决于 VMware 的磁盘分配方式和虚拟机里安装了多少软件。

虚拟机文件放在 D 盘时，真正占用的是 D 盘空间。Windows 更新、安装包、录屏素材和备份都会继续增加占用，所以创建前要确认 D 盘有余量。

## 4. 安装完成后先做基础整理

进入 Windows 11 桌面后，不要马上开始录制。建议先完成这些准备：

1. 设置合适的屏幕分辨率和缩放比例。
2. 运行 Windows Update，完成必要更新。
3. 安装浏览器、压缩软件、截图工具和教程需要的软件。
4. 设置下载目录和录屏素材保存目录。
5. 删除桌面上不需要的快捷方式，保持演示画面干净。
6. 关闭不必要的开机启动项，减少录制时的干扰。

如果 VMware Tools 暂时无法安装，也可以先跳过。它主要影响鼠标、分辨率、剪贴板等使用体验，不是 Windows 安装成功的必要条件。

## 5. 为什么 OBS 建议装在主机

OBS 最好安装在主机系统，而不是虚拟机里。这样可以直接录制 VMware 窗口，也能减少虚拟机的性能压力。

在 OBS 中可以添加：

- **窗口采集**：只录制 VMware 窗口
- **显示器采集**：录制整个主机屏幕

第一次使用时，建议先添加“窗口采集”，选择 VMware 窗口并录制十秒钟测试。如果画面是黑的，再尝试“显示器采集”，或者检查 VMware 窗口是否最小化。

录制时可以把 OBS 最小化，避免 OBS 自己出现在画面里。教程需要展示主机和虚拟机切换时，再使用显示器采集。

## 6. VMware Player 没有快照怎么办

VMware Workstation 17 Player 的界面里可能没有完整的“快照”功能。遇到这种情况，可以用复制整个虚拟机文件夹的方式做备份。

操作前先关闭 Windows 虚拟机和 VMware，然后复制：

```text
原虚拟机：D:\VMware\Windows-教程录制
备份副本：D:\VMware\Windows-录制环境备份
```

安装完所有基础软件后再复制一次，这个副本就相当于“录制环境备份”。以后测试陌生软件前，可以先保留一个干净副本，出问题时再用副本恢复。

恢复时不要在虚拟机运行中直接覆盖文件。先关机并退出 VMware，再把当前文件夹改名，把备份副本复制回原位置，最后打开其中的 `.vmx` 文件。VMware 如果询问虚拟机是“移动”还是“复制”，恢复副本时通常选择“我已复制它”。

## 7. 一套适合新手的工作流程

```text
创建 Windows 11 虚拟机
        ↓
安装浏览器、截图工具和演示软件
        ↓
关闭虚拟机，复制一份基础环境备份
        ↓
在虚拟机里完成教程操作
        ↓
主机 OBS 录制 VMware 窗口
        ↓
整理视频和截图，发布到博客与公众号
```

这样做的好处是：教程操作和日常电脑环境分开，录制失败也不会影响主机；下一次要演示同一流程时，还可以从备份环境重新开始。

## 最后提醒

- 虚拟机内存不要超过主机长期可用内存。
- 虚拟硬盘放在哪个盘，就会占用哪个盘的空间。
- 录屏素材通常比系统本身更占空间，最好单独规划目录。
- 不要把来历不明的软件直接安装到主机，先在虚拟机里测试。
- Windows 激活和软件授权要遵守微软及软件开发者的许可规则。
