下载 Windows 镜像、开发工具或其他大文件时，浏览器经常会出现速度忽快忽慢、断点续传不稳定的问题。Free Download Manager（简称 FDM）可以把一个文件拆成多个连接并行下载，也能在中断后继续任务。

不过，FDM 不是“突破带宽上限”的魔法工具。如果文件服务器本身限速、网络拥堵，或者无线网络信号不稳定，盲目增加连接数反而可能更慢。下面是我在 Windows 上整理的一套稳妥设置。

## 1. 从可信来源安装 FDM

建议从 [FDM 官方下载页](https://www.freedownloadmanager.org/download.htm) 获取安装包。官方页面同时提供 Chrome 和 Firefox 扩展，安装扩展后，浏览器里的下载链接可以自动交给 FDM 处理。

安装时可以使用默认选项。程序装在 C 盘还是 D 盘，通常不会改变下载速度；真正占空间的是下载文件和临时文件，所以更值得调整的是下载保存目录。

这是 FDM 的主界面：下载任务、搜索、添加下载和底部的速度状态都集中在一个窗口里，开始下载后可以直接在这里观察进度。

![FDM 主界面展示](/images/fdm-interface.png)

## 2. 先设置下载保存位置

打开 FDM 的设置，把默认下载目录改到空间充足的磁盘，例如：

```text
D:\Downloads
```

如果准备下载 Windows ISO 这类几十 GB 的文件，最好提前确认目标磁盘有足够的可用空间。下载过程中还可能产生临时占用，不要只按文件标称大小预留空间。

## 3. 调整连接数，而不是直接拉满

在 FDM 的流量或连接设置中，可以调整单个任务的分段数、同时下载任务数和速度限制。建议先从以下数值开始：

| 设置 | 建议值 | 说明 |
| --- | ---: | --- |
| 单个任务连接数 | 8 | 大多数服务器的稳妥起点 |
| 同时下载任务数 | 1–2 | 避免多个任务争抢带宽 |
| 速度限制 | 不限制 | 需要浏览网页时再开启限制 |

如果速度没有改善，可以尝试把单个任务连接数改为 12；如果出现频繁重连、速度掉到 0 或服务器报错，就退回 4 或 8。FDM 官方也提醒，分段数受服务器和网络条件影响，并不是越多越快。

## 4. 让浏览器正确交给 FDM

### 方法一：复制下载链接，手动交给 FDM

这个方法最稳定，适合网页没有自动跳转，或者你想明确控制下载位置的情况。

1. 在网页上找到真正的下载按钮或文件链接。
2. 右键点击它，选择“复制链接地址”（Edge/Chrome 都是这个名称）。
3. 打开 FDM，点击顶部的“添加下载”。
4. 把刚复制的链接粘贴到地址框，确认文件名和保存位置。
5. 点击“下载”，任务就会出现在 FDM 列表中。

如果粘贴后提示链接失效，通常是因为网站生成的是临时链接。回到原网页重新登录，再复制一次最新链接即可。不要直接复制浏览器地址栏的网址，那通常只是网页地址，不是文件下载地址。

### 方法二：安装扩展，让浏览器自动跳转到 FDM

这个方法适合经常下载 `.iso`、`.zip`、`.exe` 等文件，不想每次手动复制链接的情况。

1. 先打开 FDM，保持它在后台运行。
2. 从 [FDM 官方下载页](https://www.freedownloadmanager.org/download.htm) 安装对应浏览器的官方扩展。
3. 在浏览器的扩展管理页面确认扩展已启用；如果浏览器提示允许访问下载内容，请选择允许。
4. 回到文件下载网页，正常点击“下载”。
5. 浏览器会把下载任务交给 FDM，随后在 FDM 窗口中确认文件名、保存位置，再点击开始。

下面是 FDM 的“浏览器集成”设置页。安装扩展后，确认“拦截浏览器所有下载”等自动接管选项已开启；如果只想让特定格式交给 FDM，也可以使用“通过文件格式跳过文件”进行筛选。

![FDM 浏览器集成设置](/images/fdm-browser-integration.png)

如果点击后仍然由浏览器直接下载：确认 FDM 正在运行、扩展没有被停用，并重启一次浏览器。登录后才能下载的文件，要先在网页完成登录，再点击下载。

## 5. 速度越来越慢时，按这个顺序排查

### 先看是不是服务器限速

同一个文件用浏览器和 FDM 都很慢，通常是服务器出口或当前网络的问题。此时继续增加连接数意义不大。

### 检查 FDM 是否启用了限速

查看顶部的流量模式、速度限制和计划任务。有些模式会在检测到浏览器活动时自动降低下载速度，适合边下载边上网，但不适合全速下载。

### 暂停其他下载和云同步

网盘同步、系统更新、游戏平台更新都会占用带宽。先暂停它们，再观察 FDM 的实时速度。

### 优先使用有线网络

如果条件允许，用网线连接路由器；使用 Wi-Fi 时尽量靠近路由器，并避免让虚拟机、视频会议和大文件下载同时抢占网络。

### 不要频繁暂停和重启

部分服务器会限制短时间内反复建立连接。遇到速度波动时，先等待几分钟观察，而不是连续删除任务、重新添加。

## 6. 安全使用建议

- 只从软件官网、开发者仓库或可信镜像下载文件。
- 下载完成后检查文件大小和校验值；官方提供 SHA-256 时，优先进行校验。
- 不要为了“加速”安装来历不明的破解插件、所谓高速节点或修改版下载器。
- 下载 Windows ISO 时，优先使用微软官方页面；FDM 只是负责更稳定地传输文件，并不会改变镜像内容。

## 一套可以直接照抄的配置

如果只是下载 Windows ISO 或开发工具，可以先这样设置：

```text
下载目录：D:\Downloads
单任务连接数：8
同时下载任务：1
速度限制：不限制
浏览器扩展：已安装并启用
网络：优先使用有线网络
```

设置完成后先下载一个较大的、来源可信的文件进行对比。如果速度稳定，就不必继续增加连接数；稳定、可续传，往往比短时间的峰值速度更重要。
