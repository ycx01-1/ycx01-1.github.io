# FDM 实际下载速度截图展示设计

## 目标

在现有 FDM 教程中加入一张真实下载截图，让读者直观看到一次实际下载速度表现。

## 位置

保留原有“FDM 主界面展示”图片，在其后新增三级小节“实测下载速度”。不替换原图，也不改变后续章节编号。

## 内容

- 图片文件保存为 `source/images/fdm-actual-speed.png`。
- 截图展示 Docker Desktop Installer.exe 下载任务：文件大小 629 MB、进度 49%、实时速度 9.13 MB/s、预计剩余 1 分 23 秒。
- 配文明确这是一次实际测试，具体速度仍受用户网络、下载服务器和当时网络状况影响。

## 隐私与发布

视觉检查未发现账号、文件路径、API Key 或其他敏感信息。截图中的文件名、下载进度和速度可公开展示。

## 验证

1. Hexo 构建成功。
2. 文章页面正常加载图片。
3. 桌面端和移动端图片不溢出正文区域。
4. GitHub Pages 部署成功，线上图片返回 HTTP 200。
